# LiveCode Typer Demo 0.3.4

Отдельная демонстрационная копия LiveCode Typer для Windows и macOS. В ней заранее добавлены семь C# заданий из приложенного файла. Основное приложение и его данные эта копия не меняет.

## Быстрый старт

1. Запусти `live-code-typer-demo.exe`.
2. Перейди в редактор кода или текстовое поле.
3. Нажми `Alt+1` … `Alt+7`: выбранное задание включится и начнёт набираться при нажатиях случайных клавиш.
4. Боковая кнопка мыши 4 переключает на следующее задание; кнопка 5 — на предыдущее. Если печать уже включена, переключение её не останавливает.
5. Пробелы и переносы строк из кода вводятся автоматически. Остановка доступна кнопкой в приложении и горячей клавишей экстренной остановки.

После `Alt+1` … `Alt+7` или переключения мышью возвращаться в окно LCT не нужно: следующий код сразу продолжает печататься в активном редакторе.

Семь подготовленных заданий закреплены от случайного редактирования и удаления. Alt+1–Alt+7 выбирают их напрямую; кнопку мыши 4/5 можно нажимать несколько раз, например дважды вперёд для перехода с задания 3 на задание 5.

## Кнопки

| Действие | Сочетание |
| --- | --- |
| Задание 1–7 | `Alt+1` … `Alt+7` |
| Следующее задание | Кнопка мыши 4 |
| Предыдущее задание | Кнопка мыши 5 |
| Печать / пауза | `Ctrl+Alt+Space` |
| С начала | `Ctrl+Alt+R` |
| Закрепить / открепить | `Ctrl+Alt+L` |
| Экстренная остановка | `Ctrl+Alt+Escape` |

Alt+1–Alt+7 зарезервированы для заданий. Остальные сочетания меняются в окне **Горячие клавиши**.

Настройки и данные демоверсии хранятся отдельно в папке `portable-data` рядом с программой. Демоверсия не переносит в неё библиотеку основного приложения.

## Онлайн-комната

На компьютере, который будет ведущим, запусти сервер:

* В готовом архиве Windows запусти `Start-Room-Server.cmd`.
* В готовом архиве macOS запусти `Start-Room-Server.command`.
* Из исходников используй команду ниже.

```powershell
cargo run --release --bin live-code-room-server
```

Для запуска демоверсии из исходников используй `cargo run --release --bin live-code-typer-demo`.

Сервер покажет готовые ссылки комнаты с кодом внутри. Открой ссылку с IP ведущего и отправь её участникам: на Windows и Mac её можно открыть в браузере. Чтобы задание комнаты попало в редактор участника, тот запускает настольное приложение и подключается к комнате. Браузерная панель управляет заданиями, но сама не печатает в редактор.

Комната рассчитана на локальную сеть или Wi-Fi. Используйте ссылку с IP ведущего, а не `localhost`, на других компьютерах.
