LiveCode Typer — Windows x64 — версия 0.3.1

БЫСТРЫЙ СТАРТ
1. Распакуйте архив в папку, где у вас есть право сохранять файлы.
2. Запустите live-code-typer.exe.
3. В первом окне следуйте короткой инструкции: вставьте текст, включите печать и перейдите в нужное поле.
4. Нажимайте любые клавиши. Приложение отправит следующий символ из текста; пробелы и Enter вводятся сами.
5. Откройте «Горячие клавиши», чтобы изменить сочетания. Закрепите фрагмент, чтобы защитить его от изменений.

ПЕРЕНОС ИЗ ПРЕДЫДУЩЕЙ ВЕРСИИ
Клиент перенесёт фрагменты, сочетания и настройки комнаты из %AppData%\LiveCodeTyper\library.json в portable-data.
При первом запуске сервера туда же перенесутся задания, участники и история из %AppData%\LiveCodeTyper\Server\room.json.
Исходные файлы останутся на месте.

ОНЛАЙН-КОМНАТА В ЛОКАЛЬНОЙ СЕТИ
1. На компьютере ведущего запустите Start-Room-Server.cmd и оставьте окно открытым.
2. Если Windows спросит о брандмауэре, разрешите доступ только для частной сети.
3. Скопируйте готовую ссылку комнаты из окна сервера и отправьте её участникам на Windows или Mac.
4. Для получения текста в редакторе участник запускает live-code-typer.exe, открывает «Онлайн-комнату», вставляет ту же ссылку и вводит имя.
5. Браузерная панель подходит для управления заданиями, но не печатает в редактор. В ней можно скопировать приглашение для группы.
6. У всех участников одинаковые права. Сервер сохраняет данные в portable-data.

ЕСЛИ ССЫЛКА НЕ ОТКРЫВАЕТСЯ
Убедитесь, что серверное окно открыто, устройства подключены к одной Wi-Fi сети, а Windows разрешил доступ для частной сети. Для других устройств используйте ссылку с IP ведущего, а не localhost.

БЕЗОПАСНОСТЬ
Комната работает по HTTP без входа и шифрования. Используйте её только в доверенной локальной сети; не перенаправляйте порт в интернет.

ПЕРЕНОСИМОСТЬ
Настройки приложения и данные сервера находятся в portable-data рядом с программами. Скопируйте всю папку выпуска, чтобы перенести их на другой Windows x64 компьютер.
